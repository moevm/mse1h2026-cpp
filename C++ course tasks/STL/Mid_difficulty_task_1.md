# Задание

Напишите функцию `analyzeArray`, которая анализирует массив целых чисел и выводит все результаты на экран. Необходимо использовать контейнеры и алгоритмы STL.

**Функция `analyzeArray`**
- Принимает:
    - `const int* arr` — указатель на массив целых чисел
    - `size_t size` — размер массива
- Выводит следующие данные (каждое на новой строке):
    1. Минимальное значение в массиве
    2. Максимальное значение в массиве
    3. Сумму всех элементов
    4. Среднее арифметическое
    5. Количество четных чисел
    6. Массив в обратном порядке (элементы через пробел)
    7. Массив, где каждый элемент умножен на 2 (элементы через пробел)
- Ничего не возвращает (`void`)
