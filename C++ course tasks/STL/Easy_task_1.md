# Задание

Напишите функцию `printVectorInfo`, которая принимает вектор и выводит информацию о нем: его размер, выделенную память и проверку на пустоту. 

**Функция `printVectorInfo`**
- Принимает: `const std::vector<int>& vec` (константная ссылка на вектор целых чисел)
- Выводит три строки:
    - `"Size: "` + значение `vec.size()`
    - `"Capacity: "` + значение `vec.capacity()`
    - `"Empty: "` + `"yes"`, если вектор пуст, или `"no"`, если не пуст
- Пример вывода:
```
Size: 3
Capacity: 3
Empty: no
```
- Ничего не возвращает (`void`)
